# Zeiss arivis Pro

Zeiss arivis Pro is designed for large, complex 3D and 4D microscopy datasets, enabling interactive visualization, segmentation, and quantitative analysis at scale. It combines classical, machine-️ML, and deep-learning–based tools in an integrated workflow, making it well suited for advanced spatial and volumetric analyses.

### Modular image analysis software for multidimensional, large-scale imaging data
- Interactive analysis
- Automated end-to-end image analysis pipelines:
	- Image processing
	- 3D Segmentation
	- Tracking
	- Object and Track analysis
